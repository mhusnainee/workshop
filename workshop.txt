1. BRAND SYSTEM & STRUCTURAL DEFINITION
1.1 Brand Identity & Local Context
The website is designed for "Steel Bending Maintenance Workshop" (ورشة صيانة محل خليفة), a highly experienced heavy industrial repair shop located on Abi Shawk Street, branching from Prince Salman Road in Al-Sinaiyah al-Qadimah, Riyadh. The workshop specializes in repairing heavy steel cutting and bending machinery, electric motor rewinding, site generator maintenance, and professional field power tools.

Suggested Brand Name (B2B Appeal): Steel Bending Repair | خليفة لصيانة المعدات الصناعية

Suggested Logo Concept: A clean modern monogram combining the mechanical geometry of a heavy shearing blade with the circular stator teeth of an electric motor rotor.

Primary Typography: Inter (Latin sans-serif) combined with Cairo (Arabic sans-serif) to ensure high readability and clean alignment.

Base Color Palette:

Primary (Industrial Cobalt Blue): #1E40AF (Light Theme) / #3B82F6 (Dark Theme)

Accent (Heavy Machinery Amber): #D97706 (Light Theme) / #F59E0B (Dark Theme)

Neutral Light: Slate 50 (#F8FAFC) / Slate 100 (#F1F5F9)

Neutral Dark: Deep Charcoal (#090D16) / Dark Navy (#111827)

3.5 Dynamic Diagnostic Component (components/DiagnosticWidget.tsx)
This interactive, client-side React component acts as a "live diagnostics manual". Users can select their machine type to load corresponding real-world failure cases, physical mechanics explanations, and solution steps.

TypeScript
'use client';

import React, { useState } from 'react';

const troubleshootingDatabase = {
  bender:,
  cutter:,
  motor:
};

type CategoryKey = 'bender' | 'cutter' | 'motor';

export default function DiagnosticWidget() {
  const [category, setCategory] = useState<CategoryKey>('bender');
  const = useState<number>(0);

  const activeCases = troubleshootingDatabase[category];

  return (
    <div className="border border-slate-200 dark:border-slate-800 rounded-xl overflow-hidden bg-white dark:bg-[#111827] shadow-lg">
      
      {/* Tab selection */}
      <div className="flex border-b border-slate-200 dark:border-slate-800 bg-slate-50 dark:bg-slate-900/50">
        {(['bender', 'cutter', 'motor'] as CategoryKey).map((tab) => (
          <button
            key={tab}
            onClick={() => { setCategory(tab); setSelectedCase(0); }}
            className={`flex-1 py-4 text-xs sm:text-sm font-bold capitalize transition-all duration-200 ${
              category === tab 
               ? 'bg-white dark:bg-[#111827] text-blue-600 dark:text-blue-400 border-b-2 border-blue-600 dark:border-blue-400' 
                : 'text-slate-500 hover:text-slate-800 dark:hover:text-slate-300'
            }`}
          >
            {tab === 'bender' && 'Benders (مكائن الثني)'}
            {tab === 'cutter' && 'Cutters (مكائن القص)'}
            {tab === 'motor' && 'Motors (الدينموات)'}
          </button>
        ))}
      </div>

      <div className="p-6 grid grid-cols-1 md:grid-cols-12 gap-6">
        
        {/* Symptoms List (Left) */}
        <div className="md:col-span-5 space-y-2">
          <div className="text-xs font-mono text-slate-400 uppercase tracking-wider mb-2">Select Diagnostic Symptom</div>

            <button
              key={index}

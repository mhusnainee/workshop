# Khalifa Industrial Repair Website
## ورشة صيانة خليفة للمعدات الصناعية

A Next.js 14+ bilingual (English/Arabic) website for **Khalifa Maintenance Workshop**, located on Abi Shawk Street, Al-Sinaiyah al-Qadimah, Riyadh, Saudi Arabia.

---

## Tech Stack

- **Next.js 14+** — App Router
- **TypeScript** — Type safety throughout
- **Tailwind CSS** — Utility-first styling
- **Framer Motion** — Smooth micro-animations
- **next-themes** — Light/Dark mode toggle
- **Lucide React** — Icon library
- **Cairo + Inter fonts** — Bilingual typography

---

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## Pages

| Route | Description |
|-------|-------------|
| `/` | Homepage — Hero, stats, service highlights |
| `/services` | 6 service verticals with bilingual cards |
| `/troubleshooting` | Machine specs, physics formulas, interactive diagnostics |
| `/contact` | Phone/WhatsApp CTAs, inquiry form, Google Maps embed |
